# 0.1.5 배포 기록

2026-11-11 사용자 승인과 npm의 정상 브라우저 인증을 거쳐 `@kyuob/postrail@0.1.5`를 공개했다. 공식 registry의 latest가0.1.5이고 검수한 압축 파일과 공개 파일의 바이트가 같음을 확인했다.

공통 옵션 파서, 명령별 출력 함수, 공개 오류 코드 계약과 고정 Prettier CI 검사를 포함한다. 기존 전송 보호 규칙을 유지한다. 상세 내용은 [유지보수 기록](maintenance-20261110.md)을 따른다.
