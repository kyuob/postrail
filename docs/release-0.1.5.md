# 0.1.5 배포 기록

2026-11-11 사용자 승인으로 유지보수 변경의 npm 배포를 준비했다. 준비 기록만으로 공개 완료를 뜻하지 않는다.

공통 옵션 파서, 명령별 출력 함수, 공개 오류 코드 계약과 고정 Prettier CI 검사를 포함한다. 기존 전송 보호 규칙을 유지한다. 상세 내용은 [유지보수 기록](maintenance-20261110.md)을 따른다.

후보 커밋의 CI, 검수한 tarball의 registry 바이트 일치, 공개 버전의 격리 설치 확인 후 결과를 기록한다. KeyFlow 추가 인증이나 실제 블로그 전송은 실행하지 않는다.
