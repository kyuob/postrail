# 7단계 배포 검수 기록

2026-11-10. 설치·로그인·문제 해결·기여·보안 문서, 로컬 패키지·깨끗한 환경 설치, 오프라인 CI와 마지막 비공개 다중 전송을 검수한다. 패키지 공개·태그·GitHub 릴리스·공개 글 발행은 8단계로 남긴다. KeyFlow 추가 검증은 수행하지 않는다.

| 항목 | 상태 | 증거·한계 |
| --- | --- | --- |
| 한영 README·설치·로그인·FAQ·지원표 | 로컬 검사 통과 | 22개 문서·100개 로컬 링크, 예제 검증·공통 dry-run 실행 |
| 기여·보안·변경 기록·이슈/PR 양식 | 작성·독립 검토 완료 | 비공개 제보 기능의 활성화를 가정하지 않음 |
| 로컬 패키지 파일 목록·bin·의존성 | 통과 | 허용된 30개 파일, tarball 링크·민감 경로 제외, 설치 bin 확인 |
| 별도 소비자 폴더 설치·오프라인 CLI | 통과 | macOS ARM64·Node22.22.2·Bun1.3.13, 인증·발행 없이 실행 |
| Node22/24·macOS/Linux/Windows CI | 설정 완료·원격 실행 대기 | 오프라인 6조합·Linux 패키지 2조합. 실제 실행 통과로 표현하지 않음 |
| 마지막 비공개/초안 공통 다중 전송 | 통과 | 기존 승인 본문에 새 검증 ID만 부여. Velog/Tistory private와 Velog/Blogger draft의 4개 글 생성·같은 ID 수정·재조회·skip·원본 보존 확인 |
| 이미지·코드·표의 실제 화면 표시 | 미검증 | API 저장·조회 성공으로 대신하지 않음 |

개별 어댑터의 이전 실계정 결과는 [별도 기록](bundled-validation-results.md)을 따른다. 원고·계정·게시글 ID·해시·개인 실행 증거는 공개 문서에 넣지 않고 ignored `.postrail/`에 보관한다. 전체 지원을 주장하는 `liveVerified` 플래그를 근거 없이 변경하지 않는다.

로컬 회귀 152개, 문서·예제 검사, 패키지 설치와 독립 소스/문서 검토를 통과했다. 실제 다중 전송은 독립 로컬 검수를 끝낸 뒤 마지막 기능 검증으로 수행했다. 새로운 KeyFlow 인증·검증·전송, 공개 글, 삭제, registry 업로드, 태그·릴리스는 실행하지 않았다.

현재 7단계의 문서·로컬 패키지 검수·CI 구성과 지정된 마지막 다중 전송은 완료 범위다. 원격 CI의 Node22/24·OS별 실제 실행과 이미지·서식 육안 확인은 별도 미검증 상태로 남기며 첫 공개 릴리스 전 결과를 확인해야 한다. 보안 비공개 제보 설정이 활성화됐다고 가정하지 않는다.

KeyFlow는 같은 원고 ID·계정·프로젝트 이력에서 기존 글 ID를 재사용해 수정한다. 실제 기존 검증에서도 같은 ID 수정이 확인됐다. 미구현인 기능은 원격 수동 수정 충돌 검사와 원격 get이며, 수정 API 실패를 뜻하지 않는다. 외부에서 쓰던 새 초안 전용 스킬의 게시 정책과 Postrail의 업데이트 동작은 구분한다.
