# 7단계 배포 검수 기록

2026-11-10. 설치·로그인·문제 해결·기여·보안 문서, 로컬 패키지·깨끗한 환경 설치, 오프라인CI와 마지막 비공개 다중 전송을 검수했다. 이후 원격CI와 승인된 공개 글 검수까지 확인했다. 패키지·태그·GitHub릴리스는 [첫 릴리스](release-0.1.0.md)에서 관리한다. KeyFlow추가 검증은 수행하지 않는다.

개별 어댑터의 이전 실계정 결과는 [별도 기록](bundled-validation-results.md)을 따른다. 원고·계정·게시글 ID·해시·개인 실행 증거는 공개 문서에 넣지 않고 ignored `.postrail/`에 보관한다. 전체 지원을 주장하는 `liveVerified` 플래그를 근거 없이 변경하지 않는다.

초기 단계에서 로컬 회귀152개, 문서·예제 검사, 패키지 설치와 독립 소스/문서 검토를 통과했다. 실제 비공개 다중 전송을 마지막 기능 검증으로 수행했다. 이후 공개 글 작업에서 회귀167개와 독립 검토, 저장·화면 검증을 통과했다. 새로운KeyFlow인증·검증·전송이나 글 삭제는 수행하지 않았다. registry업로드·태그·릴리스 상태는 첫 릴리스 기록을 따른다.

7단계의 문서·로컬 패키지 검수·CI실행과 지정된 마지막 다중 전송을 완료했다. 공개 글 검수는 macOS Chrome의 지정 원고 범위로 추가됐으며 OS별 로그인·모바일까지 확대하지 않는다. 보안 비공개 제보 설정이 활성화됐다고 가정하지 않는다.

KeyFlow는 같은 원고 ID·계정·프로젝트 이력에서 기존 글 ID를 재사용해 수정한다. 실제 기존 검증에서도 같은 ID 수정이 확인됐다. 미구현인 기능은 원격 수동 수정 충돌 검사와 원격 get이며, 수정 API 실패를 뜻하지 않는다. 외부에서 쓰던 새 초안 전용 스킬의 게시 정책과 Postrail의 업데이트 동작은 구분한다.
