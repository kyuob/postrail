# 0.1.4 배포 기록

## 변경 범위

- npm 배포 문서를 사용자 가이드 목록으로 제한하고 패키지의 Markdown 링크를 검사한다.
- 수동 Chrome 로그인에 실행 파일 경로 옵션과 환경 변수 설정을 제공한다.
- 공통 publish의 KeyFlow 실패 안내를 로컬 상태 확인 경로와 연결한다.
- 공개된 이전 버전과 현재 소스의 상태를 문서에서 구분한다.

## 검증과 배포 상태

2026-11-10에 `@kyuob/postrail@0.1.4`를 npm에 공개했다. 공식 registry에서 `latest: 0.1.4`, SHA512 무결성과 검수한 tarball의 정확한 바이트 일치를 확인했다. registry에서 받은 버전의 새 소비자 설치·실행, 격리 전역 설치·PATH·삭제도 macOS arm64, Node22.22.2에서 통과했다. 실제 사용자 전역 설치는 변경하지 않았다.

- 배포 소스 커밋: `9cd3b725380659f1ebae1711e0c376072f3ff712`
- [해당 커밋 CI](https://github.com/kyuob/postrail/actions/runs/42830721757):9개 작업 통과. macOS·Linux·Windows의 Node22/24 오프라인 검사와 패키지·문서 검사를 포함한다.
- 로컬 검증: 회귀260개 통과, 문서31개·로컬 링크127개 검사 통과, 배포 dry-run 통과. 별도 읽기 전용 릴리스 검토에서 차단 문제 없음.
- 배포 파일: 허용 목록29개. 내부 검수 기록은 배포물에서 제외했다.
- tarball SHA256: `1432317f5c48ed3c7eb194b4b52e9f2a3b85aed3278edbcf13326fc30dd76217`

후속 정리: 사용자가 단일 npm 명령의 예외를 허용하고 브라우저 인증을 마친 뒤 `0.0.0-stage`에만 사용 중단 경고를 추가했다. 공식 registry에서 해당 경고와 `latest: 0.1.4`, 최신 버전에 사용 중단 경고가 없음을 확인했다. 버전 삭제나 패키지 전체 사용 중단은 하지 않았다. Bun 전용 규칙은 이 명령 한 번을 제외하고 유지한다.

실제 비표준 경로의 Chrome 계정 로그인은 이번 릴리스에서 확인하지 않았다. 추가 KeyFlow 실계정 검수나 블로그 전송은 진행하지 않는다. 인자 파서 통합, 출력 구조 개편과 전체 포맷 변경은 포함하지 않는다.
