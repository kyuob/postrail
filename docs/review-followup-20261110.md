# Claude 리뷰 후속 판정

2026-11-10. Codex가 현재 소스와 공식 npm registry를 직접 대조한 결과다. 전달받은 Claude의285검사 통과 보고는 참고이며, 이번 수정의 검증은 별도로 수행한다. 수정 시작시 postrail은 clean이었고 겹치는 claim은 없었다.

## 채택

- **2 배포 문서:** 공식 registry에0.1.3이 latest로 공개돼 있음을 확인해 한영 README·설치·기여·npm문서·CHANGELOG·현재 품질 상태를 정정했다. 옛0.1.0/0.1.2 당시 기록은 역사로 보존하고 이번 소스 수정은 Unreleased로 구분한다.
- **3 npm 배포 파일:** `docs` 전체 대신 사용자 문서16개를 명시했다. 내부 검수·실계정 증거·작업 단계 기록은 저장소에 보존한다. 설치된 문서에서 그 기록을 참조할 때는 GitHub 링크를 사용하며, 패키지 스모크가 archive의 모든 Markdown 상대 링크도 검사한다. 임의의 새 docs파일은 자동 포함되지 않는다.
- **8 Chrome 경로:** 로그인 전용 `--chrome-path`와 공통 세션의 `POSTRAIL_CHROME_PATH`를 연결했다. 명시 옵션 우선, 절대 앱 내부 실행 경로만 허용한다. 수동 창과 종료 후 계정 확인에 같은 경로를 사용한다. 기본 경로·고정 URL·전용 프로필·sandbox·사용자 직접 인증·shell:false는 유지한다. 새 위치의 실계정 로그인 증거는 없다.
- **9 공통 상태:** 기존 KeyFlow 로컬 status를 공통 실패 보고에 연결했다. unknown/pending/failed와 저장ID를 확인할 수 있으면 보존하고, 원격get이 없는 어댑터는 local inspection을 안내한다. 추가 원격조회·인증·공식CLI호출·쓰기 재시도를 추가하지 않았다. 공통 모의 어댑터 회귀만 추가하며 KeyFlow 전용 acceptance는 다시 열지 않는다.

## 수정해 받아들인 지적

- **1 stage버전:** 공식 registry에 `0.0.0-stage`가2파일·337바이트로 남아 있으나 latest는0.1.3이다. 일반 설치를 가로채는 상태나 보안 사고로 분류하지 않는다. [npm 삭제 정책](https://docs.npmjs.com/policies/unpublish/)은72시간 이후에도 의존성·다운로드·소유자 요건에 따른 삭제를 허용하므로 ‘시간 경과 후 무조건deprecate’는 부정확하다. 삭제는 되돌릴 수 없고 버전 재사용도 불가하므로 이번 로컬 수정에 포함하지 않았다. 공개 삭제·사용 중단 표시·새 버전 배포는 별도 명시 승인이 필요하다.

## 지금은 보류

- **4 파서 통합:** 중복은 있으나 허용 옵션·필수값·확인 시점은 플랫폼과 명령마다 다르다. 옵션 하나를 추가할 때 반드시 여섯 파서를 바꾸는 구조는 아니다. 공통 파서의 입력 계약을 정하고 별도 변경으로 검증한다.
- **5 출력 디스패치:** 현재 사용자 결함보다 확장성 개선이다. 이번 제한된 버그 수정에 새 어댑터 인터페이스를 섞지 않는다.
- **6 전체 포맷팅:** 긴 줄은 실제 검토 비용을 높이지만, 전체 서식 변경은 이번 기능 diff를 가린다. 테스트 개수만으로 안전을 보장하지 않는다. 포맷 설정·고정 버전·CI 도입은 기능 변경과 분리한 커밋에서 진행한다.
- **7 오류 코드 중앙화:** 문서 누락 자동 검사는 유용하지만, 현재 정규식만으로 실제 잘못된 결과가 확인되지는 않았다. 오류 집합과 종료 코드의 계약을 먼저 정의하는 후속 범위다.

## 검증 경계

로컬 빌드·스모크·허용된 공통/세 어댑터·배포/문서 회귀와 패키지·격리 설치를 검사한다. 이미 종료된 KeyFlow 전용 검수·실계정 검증은 실행하지 않는다. registry 읽기는 공개 메타데이터만 사용하며 삭제·게시·로그인·자격증명 조회·원격 push를 수행하지 않는다. 이 문서는 npm 배포 대상에서 제외한다.

## 실제 검증 결과

- `bun run check:publish`: 빌드·스모크와260개 회귀 전부 통과. 원래 전체285개 보고와 다르게 KeyFlow 전용 파일을 제외한 허용 범위다.
- `bun run check:docs`:30개 문서·127개 상대 링크와 빈 소비자의 문서 예제 실행 통과.
- `bun run check:package`:29개 허용 파일, 내부 검수 문서 제외, 배포 문서 링크, 별도 소비자 설치, 격리 전역 설치·PATH·삭제 통과. macOS arm64 / Node22이며 실제 사용자 설치는 변경하지 않았다.
- 별도 Codex 에이전트의 읽기 전용 검토에서 차단 결함 없음. 두 클라이언트의 Playwright `executablePath` 연결은 코드로 대조했고, 실제 다른 위치 Chrome 실행·실계정 로그인은 미검증이다. 이 검토가 Claude의 새 검수였다고 표시하지 않는다.
- 로컬 수정 상태다. 패키지 버전은0.1.3으로 유지하며 새로운 배포물은 Unreleased다. 커밋·push·npm 작업은 하지 않았다.
