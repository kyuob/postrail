# 지원·검증 범위

구현, 모의 검사, 실제 계정 저장 검증, 실제 화면 확인은 다른 상태다. 이 표는 첫 릴리스나 모든 기능의 지원을 약속하지 않는다.

| 기능 | Velog | Tistory | KeyFlow | Blogger |
| --- | --- | --- | --- | --- |
| 연결 방식 | 전용 Chrome + 내부 v3 | 전용 Chrome + 내부 관리 API | 고정 버전 공식 CLI | 공식 API v3 + Desktop OAuth |
| draft | 지원 | 미지원 | 기존 계약 지원 | 지원 |
| private | 지원 | 지원 | 기존 계약 지원 | 미지원 |
| public | 구현·실계정 미검증 | 구현·실계정 미검증 | 기존 계약 | 구현·실계정 미검증 |
| 로컬 이미지 | 구현·저장 확인, 화면 미검증 | 구현·등록 확인, 화면 미검증 | 기존 제약 참고 | 미지원 |
| 같은 원격 ID 수정 | 실계정 확인 | 실계정 확인 | 기존 사용자 확정 | 실계정 확인 |
| 변경 없는 재전송 | 원격 확인 후 skip | 원격 확인 후 skip | 로컬 해시로 skip | 원격 확인 후 skip |
| 원격 수동 수정 충돌 | 검사 | 검사 | 미구현, 덮어쓸 수 있음 | 검사 |
| 원격 get | 저장 ID | 저장 ID | 미구현 | 저장 ID |
| 자동 unknown 복구 | 없음 | 없음 | 없음 | 없음 |
| 자동 로그인·쓰기 재시도·삭제 | 없음 | 없음 | 없음 | 없음 |

KeyFlow의 자세한 이미지·상태 계약은 [기존 가이드](keyflow.md)를 따른다. 추가 검증을 다시 수행하지 않으며 새 검증 결과로 꾸미지 않는다.

## 실행 환경

| 범위 | macOS | Linux | Windows |
| --- | --- | --- | --- |
| 오프라인 CLI | 로컬 검수 대상 | CI 검사 대상 | CI 검사 대상 |
| Node.js | 22 이상, CI 22/24 | CI 22/24 | CI 22/24 |
| Velog/Tistory 수동 로그인 | 지원·실계정 확인 | 미지원 | 미지원 |
| Blogger 인증 저장 | 지원·실계정 확인 | 구현·실계정 미검증 | ACL 검증 전 미지원 |
| KeyFlow 인증 | 기존 공식 CLI 계약 | 공식 CLI 제약 확인 필요 | 공식 CLI 제약 확인 필요 |

CI 설정은 모든 OS의 실제 통과 증거와 동일하지 않다. 실행한 플랫폼·버전과 결과는 [7단계 검수 기록](stage7-status.md)을 확인한다. 로컬 패키지 검수도 실행한 OS와 버전만 증명한다.

공통 `publish`는 선택한 대상의 공개 상태를 그대로 사용한다. 호환되지 않는 조합은 전송 전에 거절한다. [실계정 개별 검증](bundled-validation-results.md)과 마지막 공통 다중 전송 결과를 구분한다. 이미지·코드·표의 육안 확인, 만료 후 인증 갱신, 공개 발행·되돌리기는 별도 검증 범위다.
